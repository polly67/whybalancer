# whybalancer - Linux Machine Benchmark

Automated GitHub Actions workflow to benchmark:
- **CPU Speed:** Single-threaded and multi-threaded sysbench prime calculation speed.
- **RAM Capacity & Speed:** Total memory capacity, available memory, memory read and write throughput.
- **Disk IOPS & Bandwidth:** 4KB Random Read/Write IOPS and 1MB Sequential Read/Write bandwidth using `fio`.
